MorphWizard - редактор морфологических словарей
================================================

MorphWizard - программа редактирования морфологического словаря (файл
morphs.json). Программа позволяет искать, добавлять, удалять и
редактировать парадигмы. Сайт программы - www.aot.ru.

История. Программа первоначально была написана Константином Серебряным
(1999), потом во многом переделана Алексеем Сокирко (2002-04) и дополнена
Николаем Кецарисом (2003). Часть функций написал Сергей Григорьев (2001).
До 2026 года программа существовала только под Windows (MFC). В 2026 году
Алексей Сокирко вместе с Claude (ИИ-ассистент компании Anthropic) переписал
ее на Qt6, и теперь она работает под Linux, Windows и macOS.

Исходники: Source/gui/morphwizard (интерфейс) и
Source/morph_dict/morph_wizard (ядро, общее с генератором бинарных словарей
morph_gen). Исполняемый файл - morphwizard_qt.

Содержание

1. Запуск программы и файл проекта словаря
------------------------------------------

Сборка: программа собирается вместе со всем проектом (см. readme), нужен Qt6
(компонент Widgets).

Запуск:
    morphwizard_qt [--disable-predict] [project.mwz ...]

Файлы проектов, указанные в командной строке, открываются сразу. Ключ
--disable-predict отключает построение индекса предсказания (словарь
загружается быстрее, но кнопка PREDICT не работает).

Пользователь открывает файл проекта словаря (File/Open) с расширением *.mwz.
Последние открытые проекты запоминаются в меню File/Recent Files. Можно
открыть сразу несколько словарей, каждый в своей вкладке.

Файл проекта - это JSON со следующими полями:
    MRD_FILE - путь к файлу словаря (относительно каталога проекта);
    LANG     - язык словаря (RUSSIAN, ENGLISH, GERMAN);
    USERS    - список пользователей словаря.
Например, Source/morph_dict/data/Russian/project.mwz:
    {
      "MRD_FILE": "morphs.json",
      "LANG":     "RUSSIAN",
      "USERS": [ "alex", "vse-imena", "accentor", "user2008", "yakovru", "l0pan" ]
    }
Рядом с проектом лежит таблица граммем gramtab.json.

После выбора проекта программа просит ввести имя пользователя (по умолчанию
"guest"). Пользователь guest открывает словарь только на чтение, в окне
словаря тогда видна надпись READ ONLY. Любой другой пользователь из списка
USERS может словарь изменять; его правки записываются в новую сессию
(имя пользователя, время начала и время последнего сохранения).

Протокол работы программы пишется в файл wizard.log в каталоге данных
программы (например, ~/.local/share/aot/MorphWizard под Linux).


2. Основные понятия
-------------------

Граммема - элементарный морфологический дескриптор слова. Например, "mas" -
мужской род, "acc" - винительный падеж. Набор граммем зависит от языка
(русский, английский, немецкий). Для русского языка теперь используются
латинские названия граммем (mas, fem, sg, pl, nom, gen, anim...).

Часть речи - строковая константа, которая относит слово к какому-то большому
классу слов (например, "N" - существительное, "V" - глагол).

Все разрешенные наборы вида <часть речи, граммемы> записаны в таблицу
граммем gramtab.json (у каждого языка своя: Source/morph_dict/data/<Язык>/
gramtab.json, при сборке она копируется в Dicts/Morph/<Язык>/gramtab.json).
Например, в русской таблице есть набор
    N mas,sg,nom
а набора
    N trans
там нет, поскольку переходных (trans) существительных в русском языке не
существует.

Каждому набору <часть речи, граммемы> в таблице приписан грамматический код,
или анкод (аношкинский код). Анкод - это двухбуквенный код, который
однозначно определяет набор <часть речи, граммемы>. Пользователю удобнее
видеть <часть речи, граммемы>, а программе - анкод. Иногда мы называем
<часть речи, граммемы> текстовым представлением анкода. Запись таблицы
выглядит так:
    "AA": {"p": "N", "g": ["mas", "sg", "nom"], ...}

Псевдооснова слова - неизменяемая левая часть всех словоформ слова. Для
некоторых слов псевдооснова может быть пуста, например, для слова "я"
("меня", "мной").

Набор окончаний (модель флексий, номер парадигмы) - набор пар <X, Y>, где
X - окончание, которое добавляется к псевдооснове, а Y - анкод.

Парадигма - набор всех словоформ одного слова. Каждой словоформе приписан
анкод. Текстовое представление парадигмы (slf-представление) выглядит так:
    ма'ма         N fem,nom,sg,
    ма'мы         N fem,gen,sg,
    ...
Первое слово парадигмы называется леммой, или нормальной формой слова.
Обычно все словоформы одной парадигмы принадлежат одной части речи. Для
программы парадигма - это пара <псевдооснова, набор окончаний>.

Общие граммемы (type grammems) - граммемы, которые приписаны целому слову,
а не отдельным словоформам (например, одушевленность существительного).

Модель ударений - номера ударных гласных для всех словоформ одного слова.

Набор префиксов - набор префиксов, каждый из которых может быть добавлен
к слову целиком (например, "ГИГА,ТЕРА" для слова "БАЙТ").


3. Главное окно словаря
-----------------------

Окно словаря состоит из двух панелей. С помощью левой панели пользователь
может найти, отредактировать и удалить парадигмы, с помощью правой - добавить
новую парадигму. Меню находится над окнами словарей.

Меню File:
    Open...      - открыть проект словаря;
    Save         - сохранить словарь на диск;
    Close        - закрыть текущий словарь;
    Recent Files - последние открытые проекты;
    Exit         - выход из программы. Если словарь изменен, программа
                   предложит его сохранить.

Меню Tools (действует на текущий словарь):
    1. "Save current list of words to file" - сохранить список лемм, который
       показан на левой панели, в текстовый файл. На каждой строке записано
       <лемма>;<общие граммемы>;<часть речи и граммемы леммы>.
    2. "Paradigm Export" - сохранить все парадигмы с левой панели в файл
       формата slf (раздел 5). После записи программа спрашивает, удалить ли
       экспортированные парадигмы из словаря.
    3. "Find paradigms by list of words" - найти парадигмы по списку из
       файла. Формат файла тот же, что у "Save current list of words to file":
       если сначала сохранить список, а потом найти парадигмы по этому файлу,
       получится тот же самый список. Не найденные строки программа покажет.
    4. "Paradigm Import" - добавить в словарь парадигмы из файла формата slf.
       Программа предлагает две кнопки: Test (только проверить файл на
       ошибки) и Import (проверить и добавить парадигмы в словарь). Ошибки
       записываются в файл с тем же именем и расширением .err.
    5. "Pack" - удалить неиспользуемые наборы окончаний, модели ударений и
       наборы префиксов, а одинаковые наборы окончаний объединить.
    6. "Set Paradigm No" - программа спрашивает номер набора окончаний (по
       умолчанию - номер выделенной парадигмы) и приписывает его всем
       парадигмам левой панели.
    7. "Set Accent Model No" - то же для модели ударений. Модель ударений
       можно приписать слову, только если она уже встречается в словаре
       вместе с его набором окончаний.
    8. "Show paradigm differences" - сравнить два набора окончаний.
    9. "Show accent model differences" - сравнить две модели ударений.
   10. "Accent Wizard" - поочередно открывать на редактирование парадигмы
       без ударений (все или только частично размеченные).

Меню Window: расположение окон (вкладки, каскад, мозаика) и переход между
ними. Меню Help: About.

Левая панель (EDIT/REMOVE PARADIGM)

    1. Окно ввода - сюда вводится строка, по которой ищутся парадигмы
       (кнопка FIND или Enter). Последние запросы запоминаются. Тип поиска
       задается переключателем:
        a) lemma - поиск по лемме, например, "длить". Можно написать часть
           слова со звездочкой ("дли*" или "*ить"), тогда найдутся все леммы
           с таким началом (концом). Строка между косыми чертами
           ("/дли.*/") - регулярное выражение;
        b) pos+grammem - поиск по набору <часть речи, граммемы>, например,
           "N mas,sg,nom,anim";
        c) user - поиск слов, которые последним редактировал данный
           пользователь;
        d) word form - поиск по словоформе; звездочка работает так же, как
           для леммы;
        e) gramcode - поиск по анкоду (двухбуквенному коду);
        f) accent model - поиск по номеру модели ударений;
        g) paradigm no - поиск по номеру набора окончаний.
       Список найденных парадигм можно сортировать, нажимая на заголовки
       столбцов.
    2. Кнопка REMOVE - удалить выделенную парадигму.
    3. Кнопка EDIT (или двойной щелчок по парадигме) - открыть окно
       редактирования парадигмы (раздел 4).
    4. Кнопка COMMENTS - комментарий к набору окончаний выделенной
       парадигмы.
    5. Окно Filter - сюда можно ввести номер набора окончаний или
       выражение-фильтр (например, анкод в виде <часть речи, граммемы>);
       тогда из найденных парадигм остаются только подходящие. Так можно
       комбинировать поиск: в окне ввода написать "*ать", а в фильтре -
       "N fem,sg,nom,anim", что найдет все одушевленные существительные
       женского рода, которые кончаются на "ать".

Правая панель (ADD PARADIGM)

    1. Окно ввода - новая лемма, которую пользователь хочет добавить в
       словарь. Символ '#' отделяет приставку, '|' задает префиксы новой
       парадигмы.
    2. Кнопка PREDICT - программа предскажет возможные наборы окончаний для
       новой леммы. Если такая лемма уже есть в словаре, будет выдано
       предупреждение. Поля Min. frequence (минимальная частота набора
       окончаний) и Suffix Length (длина сравниваемого окончания) и флажок
       Only main part of speeches управляют предсказанием.
    3. Список предсказанных наборов окончаний состоит из столбцов:
        Grammems     - граммемы возможной леммы;
        Type         - общие граммемы;
        Source lemma - лемма, которая служит прототипом предсказания;
        Freq         - частота данного набора окончаний в словаре;
        ParadigmNo   - номер набора окончаний;
        Prefix       - префикс;
        Forms Count  - число словоформ.
       Список можно сортировать, нажимая на заголовок столбца.
    4. Кнопка ADD - добавить новую парадигму: программа склоняет новую лемму
       по выделенному набору окончаний и открывает окно редактирования. Если
       набор окончаний не выделен, открывается пустое окно редактирования.


4. Окно редактирования парадигмы
--------------------------------

В центре окна находится текст парадигмы. На каждой строке записаны
<словоформа> <часть речи> <граммемы>, причем <часть речи, граммемы> должны
быть существующим анкодом. Например:
    ма'ма         N fem,nom,sg,
    ма'мы         N fem,gen,sg,
Пользователь может просто редактировать текст, заботясь только о том, чтобы
<часть речи, граммемы> были существующим анкодом. Первое слово каждой строки
выделено жирным; строка без ударения подсвечена розовым.

Над текстом:
    Type grammems - общие граммемы слова, например, для "Москвы" нужно
                    выбрать "sing_tant,loc,inanim";
    Comments      - комментарий;
    Fix Accent    - скопировать ударение текущей строки во все следующие
                    строки (то же делает клавиша F3);
    OK            - сохранить парадигму в словарь и закрыть окно. Если
                    какой-то набор <часть речи, граммемы> не преобразуется
                    в анкод, будет выдано сообщение об ошибке, и парадигма
                    вернется на доработку;
    Cancel        - закрыть окно без сохранения.

Справа:
    Set Para No - выбрать номер набора окончаний; парадигма будет полностью
                  перестроена по этому набору;
    Change All  - применить такое же изменение ко всем словам с тем же
                  набором окончаний (с той же или с любой моделью ударений);
    POS         - список частей речи; двойной щелчок добавляет константу
                  к тексту;
    Grammems    - список граммем; двойной щелчок добавляет граммему к тексту.

Внизу: префиксы слова (Prefixes) и кнопка Add Prefix (добавить префикс ко
всем словоформам), а также основа слова (Base), номер набора окончаний (Flex)
и номер модели ударений (Accent).

При редактировании можно также использовать:
    1. двойной щелчок по гласной - поставить ударение в текущей словоформе;
    2. клавишу F3 - поставить такое же ударение, как в текущей строке, во
       всех строках ниже нее.


5. Формат slf
-------------

Файл slf - это текстовый файл в кодировке UTF-8, в котором записан набор
парадигм, разделенных строками из пяти символов "=". В начале парадигмы
могут стоять необязательные строки:
    $type_grm = <grm>  - общие граммемы слова (через запятую);
    $prefixes = <p>    - префиксы слова (через запятую);
    $session = <s>     - последняя сессия, в которой слово редактировалось
                         (JSON-объект).
Дальше на каждой строке идут словоформы. Ударная гласная отмечается
апострофом после нее. Справа от словоформы стоят часть речи и граммемы.
Если словоформа содержит префикс, он отделяется символом '|'. Например:
=====
$type_grm = anim
$session = {"user":"alex","start":"18:20, 15 September 2004","last_save":"19:20, 15 September 2004"}
ма'ма         N fem,nom,sg,
ма'мы         N fem,gen,sg,
...
=====
$type_grm = inanim
$prefixes = ГИГА,ТЕРА
ба'йт         N mas,nom,sg,
ба'йта        N mas,gen,sg,
...

При импорте одинаковые строки внутри одной парадигмы выбрасываются.


6. Формат словаря morphs.json
-----------------------------

Словарь хранится в одном JSON-файле (UTF-8), обычно
Source/morph_dict/data/<Язык>/morphs.json. Раньше использовался текстовый
формат mrd, теперь его больше нет. Все слова записаны заглавными буквами.
Подробное описание формата - в Docs/Morph_UNIX.txt. Кратко, файл состоит из
пяти массивов:
    flexia_models - наборы окончаний: {"endings": [{"flexia": "А",
                    "gramcode": "BL"}, ...], "comments": "..."};
                    у окончания может быть поле "prefix";
    accent_models - модели ударений: номер ударной гласной для каждой
                    словоформы, считая с конца слова с нуля (255 - ударение
                    не задано);
    sessions      - сессии пользователей: {"user": "alex", "start": "...",
                    "last_save": "..."};
    prefix_sets   - наборы префиксов: ["ГИГА", "ТЕРА"];
    lemmas        - леммы: {"l": "МАМА", "f": 2476, "a": 1643, "s": 205,
                    "t": "MN"}, где l - лемма, f - номер набора окончаний,
                    a - номер модели ударений, s - номер сессии, t - анкод
                    общих граммем (необязательно), p - номер набора
                    префиксов (необязательно).

Бинарные словари для лемматизатора строит программа morph_gen (при сборке
проекта это цель MorphDicts):
    morph_gen --input project.mwz --output-folder Dicts/Morph/Russian
